Реляционная база данных — это набор взаимосвязанных таблиц, организованных по правилам 
реляционной модели. Каждая таблица состоит из строк (записей) и столбцов (полей). 
Первичный ключ уникально идентифицирует каждую запись. Внешний ключ связывает таблицы между собой. 
Нормализация — процесс устранения избыточности данных путём разделения таблиц. 
SQL — язык структурированных запросов для работы с реляционными БД. 
Основные операции: SELECT, INSERT, UPDATE, DELETE.
