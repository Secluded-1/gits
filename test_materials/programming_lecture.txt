Python — высокоуровневый язык программирования общего назначения. 
Он поддерживает несколько парадигм: процедурную, объектно-ориентированную и функциональную. 
Динамическая типизация позволяет не указывать типы переменных. 
Основные структуры данных: списки (list), кортежи (tuple), словари (dict) и множества (set). 
Функции определяются ключевым словом def. Классы создаются через class. 
Модули и пакеты позволяют организовать код. 
Python широко применяется в веб-разработке, анализе данных и машинном обучении.
